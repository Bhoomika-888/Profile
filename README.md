## ✨ Key Features & Interactive Architecture

- 🎨 **Modern Developer Aesthetics:** Built with a sophisticated Dark Navy (`#0a192f`) and Cyan (`#00f2fe`) theme with glassmorphic cards and crisp borders.
- 🌓 **Dark / Light Theme Toggle:** Seamless theme switcher with `localStorage` persistence and automatic system color-scheme detection.
- 📱 **Mobile-First Responsive Design:** Fully responsive layout with mobile drawer navigation, animated hamburger icon, and touch-friendly targets.
- ♿ **WCAG 2.1 AA Accessibility:** Accessible color contrast ratios, keyboard navigation with visible focus rings, ARIA landmark tags, skip-to-content links, and `prefers-reduced-motion` compliance.
- 🔍 **Interactive Project Showcase:** Featured **Smart Object Analyzer** card with category filtering tabs (`All`, `Machine Learning & CV`, `Planned`) and an interactive **Deep-Dive Architecture Modal**.
- 📄 **Direct Resume Integration:** Dedicated downloadable and browser-viewable PDF resume button (`assets/Bhoomika_Resume.pdf`).
- 📋 **One-Click Email Copy:** Copy email address to clipboard with instant toast notification feedback.
- ✉️ **Quick Email Composer:** Client-side formatted message composer that opens the recruiter's default mail client pre-populated with inquiry details.
- ⚡ **Zero Bloat & Peak Performance:** 100% vanilla web stack without heavy frameworks, external tracking scripts, or build friction.

## 🚀 Getting Started Locally

### Option 1: Direct File Open
Simply double-click `index.html` or open it with your favorite browser:
```powershell
# Open directly in Windows default browser
Start-Process "index.html"
```

### Option 2: Lightweight Python Server (Recommended)
Since Python is installed on your system, you can run a local development server with zero setup:
```powershell
# Navigate to repository directory
cd c:\Users\BHOOMIKA\Portfolio

# Start local server on port 8000
python -m http.server 8000
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser.

### Option 3: VS Code Live Server
1. Open this folder in **Visual Studio Code**.
2. If you have the **Live Server** extension installed, right-click `index.html` and click **"Open with Live Server"**.

## ☁️ Deployment Guide (Vercel)

This project is 100% static and pre-configured for zero-friction deployment on **Vercel**:

### Method 1: Deploy via Vercel CLI
```bash
# Install Vercel CLI (if npm is available)
npm i -g vercel

# Run deploy from the Portfolio directory
vercel
```

### Method 2: Deploy via GitHub & Vercel Dashboard
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Bhoomika Developer Portfolio"
   git branch -M main
   git remote add origin https://github.com/bhoomika-888/Portfolio.git
   git push -u origin main
   ```
2. Log in to [Vercel](https://vercel.com/).
3. Click **"Add New Project"** and import your `Portfolio` repository.
4. Leave all build settings at default (Framework Preset: **Other**, Build Command: empty).
5. Click **"Deploy"**. Your portfolio is live with free HTTPS and global CDN in seconds!
